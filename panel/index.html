这是什么

官方只有 Windows 驱动。本工具通过逆向 DeviceDriver.exe 1.0.3.3 得到 USB 协议：
· 命令通道 = USB 接口 2（HID usage FF68/61，64 字节报告）
· 数据通道 = USB 接口 3（usage FF67/61，4096 字节报告走中断 OUT）
· 屏幕 240×135 RGB565，单次最多 130 帧，帧延时 = 毫秒/2

支持功能：GIF 上传 / 文字上屏 / 纯色 / 时间校正 / 长条屏常驻动画与实时帧。
已知限制：必须有线连接；蓝牙模式键盘不暴露配置通道；上传会覆盖键盘上的自定义动画视图。
